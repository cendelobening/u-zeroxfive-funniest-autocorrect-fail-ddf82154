A single-line autocorrect fail: a routine "working from home" text to the boss gets one letter swapped by autocorrect into "twerking from home". The slip is instantly clear, the wrong word is the last thing a boss should read first thing in the morning, and the HR meeting at 9 is the punchline — the joke lands because the disaster escalates in one sentence, from a typo to a disciplinary hearing.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, exactly one line under 200 characters.
